Privacy Policy

SiddMiles — last updated 2026-08-05

SiddMiles is a private application built and used only by its two owners to track their own household credit card statements, spending, and rewards. It is not distributed, offered to, or used by the general public.

What data it accesses

With explicit Google sign-in consent, SiddMiles requests read-only Gmail access (gmail.readonly) limited to locating bank statement emails and transaction/payment alert emails from a fixed list of known bank sender domains. It does not read, modify, or send any other email.

How that data is used

Statement PDFs and alert email text are parsed — using a third-party AI service (DeepSeek) for text extraction — into structured transaction records (date, merchant, amount, category) and stored in a private database used only by the app's two owners.

What is not done with this data

Data is never sold, shared with advertisers, or used for any purpose beyond the owners' own personal finance tracking. No data is used to train third-party models beyond the per-request processing described above.

Revoking access

Either owner can revoke Gmail access at any time via Google Account → Security → Third-party access.

Contact

This is a personal project with no public support channel.
